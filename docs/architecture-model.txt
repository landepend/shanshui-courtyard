COURTYARD V2 / Blender architecture implementation

Reference: assets/concepts/courtyard-atang-anime-v2.png, left architectural half.
Generated by three idempotent bpy stages using shared 00_common.py.
Run each stage by concatenating common source and stage source in Blender MCP:
  01_body.py
  02_roofs.py
  03_gallery_export.py
The calling coordinator alone operates Blender MCP. Geometry scripts use bpy data; project paths resolve from the script filename,
an opened project .blend file, or the working directory. For MCP execution without
__file__, open blender/Courtyard.blend first or launch Blender in the project root.
No machine-specific drive paths are required.

Output:
  assets/architecture/courtyard.glb
  blender/Courtyard.blend
Independent Blender scene COURTYARD_V2, collection COURTYARD_ARCHITECTURE,
root empty CourtyardRoot. Existing character scenes are not removed.

Model construction:
- True curved hip/gable roof surfaces, overlapping barrel-tile shells with
  finite thickness, circular eave discs, visible rafters, swept fascia,
  hip ridges, closed timber gables and sculptural chiwen-inspired ridge fins.
- Red entasis columns on turned stone bases; three stacked curved bracket
  tiers, cross arms, bearing blocks, slanted ang and gold-edged carved beams.
- Thick framed lattice windows, open entrance leaves, balcony openwork,
  first/second floor interiors, 25 stair treads, landing, rails and furniture.
- Two side galleries and rear gallery with matching timber and tile language;
  plaster perimeter, stone feet, curved coping and ornamental rear windows.
- Geometry batches are one mesh per stage + part + material. Mesh extras part
  are roof/dougong/column/window/corridor; CourtyardRoot stores actual tile,
  triangle, mesh and material counts. No external texture resources.

Coordinate and runtime contract:
Design coordinates are Three.js (x, elevation, z). Mesh vertices in Blender
are (x, -z, elevation); glTF export_yup restores the game coordinate frame.
Floor heights 1.04 and 5.68. Main entry center x=-1.4, z=3.46, width 2.2;
upper entry x=0, z=2.42, width 2.4. Stair center x=3.35, width .96,
25 steps from z=3/y=1.04 to z=-2/y=5.68. Both slabs omit the region
x=2.5..4.9, z=-2.33..1.25; the top landing connects to the rear floor.
Side galleries center x=+-10,z=-.5,length13.5; rear gallery z=-9.5,length22.
Southeast action platform area x6.35..8.85,z7.8..10.2 is kept clear.
The model includes architecture only: no duplicate pond, bridge, plants,
characters, hanging lanterns, outdoor lighting or engine ground surfaces.

Validation status is reported by the coordinating task after actual Blender
execution, GLB structural inspection and in-engine visual/walkthrough checks.
Source code completion alone is not proof of final visual or runtime success.
